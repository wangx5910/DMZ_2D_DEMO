# 海湾城 2D Demo · raid-proto-2d

> 版本 v0.2 ｜ 2026-08-26 ｜ **局域网对战已接入**（ENet，最多 8 人）
> 设计文档：[../demo-2d/2D-Demo设计规范.md](../demo-2d/2D-Demo设计规范.md)

## 一、怎么跑

仓库里已经带了 **Godot 4.7.1**，不用单独装引擎。

1. `git clone https://github.com/wangx5910/DMZ_2D_DEMO.git`
2. 双击 **`运行游戏.bat`**

需要改场景时，双击 **`打开编辑器.bat`**。

> 克隆请装 [Git LFS](https://git-lfs.com)（`git lfs install`）。没装的话会只下到一个几 KB 的指针文件，点 bat 打不开。

## 一-b、局域网对战（策划联机）

同一局域网 / 同一 Wi-Fi。**一人开房，其他人加入。** 每人是独立小队（互相可以开枪），怪物由房主模拟。

### 开房（房主）

1. 启动游戏，在开局菜单点 **创建房间（房主）**
2. 把左上角显示的 `本机 IP:端口` 发给同伴（例如 `192.168.1.23:24567`）
3. 第一次联机请在 Windows 防火墙放行 Godot / 导出的 exe，端口 **24567**（游戏）和 **24568**（房间广播）

### 加入

1. 启动游戏
2. 若列表里出现房间，点一下即可；没有就手动填房主 IP，点 **加入房间**
3. 进局后左上角显示人数；其他真人头顶有 `P2` / `P3`，小地图橙色点

### 注意

- 必须同一版本、同一 `tuning_override` 尽量别各调各的（刷怪数量不一致会不同步）
- **F5 重开**会断开联机并回到菜单
- 搜不到房间：关防火墙试一下，或手机热点开一局（房主开热点更稳）
- 对战是搜打撤：其他真人默认敌对，打中会掉血

## 三、这一版做了什么

### 1. 角色 3C（参考逃离鸭科夫，纯 2D 俯视）
- 三档姿态：**行走 / 冲刺 / 潜行**，各有独立移速
- 加速度 + 刹车惯性（`accel` / `decel`），不是瞬时启停
- 冲刺代价三重：耗体力、**转向变钝**、**视野收窄**
- 体力耗尽后需回到阈值以上才能再跑（防"点跑抽搐"）
- 相机跟随 + **向鼠标方向轻微前瞻**（鼓励主动扫视）

### 2. 扇形视野 + 墙体遮断
- 前方扇形亮区（默认 ±50°，共 100°），边缘羽化
- **墙体实时遮断视线**（Godot 原生 2D 光照 + LightOccluder2D，硬件加速）
- **两级可见性**（本版关键取舍）：
  - **静态地形**（墙 / 地板）→ 压暗常亮，玩家永远看得见路
  - **动态实体**（其他玩家 / 敌人）→ 严格只在扇形内且无遮挡时可见
  - 即"地形记忆"与"实时情报"分离
- 姿态影响视野：潜行范围 ×0.86 但角度 +8°；冲刺角度 −12°

### 3. 逐格逐次搜刮
- 每个容器有 N 个独立格位，**按住 E 一格一格搜**
- **未搜索的格子完全不显示内容**（问号遮罩）→ "值不值得继续搜"永远是赌
- **中断只丢当前格进度，已搜出的格子永久保留** → "搜一半听到脚步就撤"是真实战术
- 容器有空格（`fill_chance`）→ 搜到空气的挫败是设计的一部分
- **L4 免保柜**需先读条破解（默认 6 秒）才能开始搜
- 容器外观显示搜刮进度条（哪几格搜过、搜出什么品级）

### 4. Tetris 网格背包
- 默认 **10×6 = 60 格**，物品占 1×1 到 3×2
- 拖拽摆放，拖拽中按 R 旋转 90°，绿框可放 / 红框冲突
- 右键快速拿取会**自动找最优位**（含尝试旋转）
- 核心取舍：同样 6 格，装一件红货还是四件蓝货

### 5. 基础关卡
- 字符网格描述（`scripts/world/level.gd` 的 `MAP` 常量），**改一个字符就换布局**
- 43×21 格（约 1720×840 像素），含四类空间：
  - 室内小房间群 → 验证门框窥视、拐角遭遇
  - 长走廊 → 验证视野范围与距离感
  - 中庭开阔地 → 验证开阔地视野劣势
  - 右下 L4 独立小间 → 验证"长读条 + 单一入口"的高风险点位
- 33 个容器，L1–L4 四档按 tier 原则摆放（越深越肥）
- 墙体按横向连续段合并成长条（性能 + 阴影边缘干净）

### 6. 验证能力
- **F1 调试面板**：38 个参数实时滑条 + 8 个机制开关，改完立即生效
- **机制开关做 A/B 对比**：可以直接关掉扇形视野 / 墙体遮断 / 搜刮读条 / 网格背包容量，同一张图跑两遍对比感受
- **日志导出**：每局记录全部事件（搜刮/取物/中断/姿态切换…）+ 汇总统计 + 当时参数快照
  - 位置：Godot 菜单 → **项目 → 打开用户数据文件夹 → logs/**
  - 两份：`.txt`（人读摘要）+ `.csv`（拉进 Excel 做曲线）
- **F5 一键重开**，自动导出上一局日志
- 「保存数值」按钮把当前调好的参数存下来，下次启动自动沿用

## 三·五、战斗与敌人（v0.3 新增）

### M4 枪械
全自动/单发（V 切换）、弹匣 30 + 备弹、战术换弹（2.0s，膛内有弹）vs 空仓换弹（2.4s）、连发扩散累积、ADS 压扩散降移速、距离衰减（420px 起降到 55%）、空仓自动换弹。**配件不做。**

### 搜刮（v0.4 改版）
- **按一次 E 即自动逐格读条搜到底**，不需要按住；搜刮中再按 E 主动停止
- **容器不再有空格** —— 每格读完必有东西。富度差异体现在格子数量：
  L1 平均 1.6 格 ¥108 ｜ L2 2.3 格 ¥287 ｜ L3 3.7 格 ¥848 ｜ L4 6.0 格 ¥2662
- 「搜一半就撤」仍然成立：中断只丢当前格，已搜出的永久保留

### 持枪小兵（照鸭科夫）
- **移速 / 体型 / 持枪与玩家相同**；血量 45（玩家 100）、伤害 4.3（玩家 24）
- 7 状态行为树：巡逻 → 警觉 → 追击 → 交战 → 搜索 / 查看声源 / 返回岗位
- 视野扇形 ±55° / 400px + 墙体遮挡，与玩家同一套判定（不作弊）
- **持续追击**：脱离视野后仍追 4 秒；超 1100px 或离岗 1500px 才放弃
- **交战边打边横移**，2–4 发点射，间隔 0.6–1.4 秒
- **开枪会被听到**（900px 内小兵来查看）；背后受击会朝来向反扑
- F1 勾「怪物 AI 状态可视化」可看头顶状态名与视野扇形
- **全图 200 个，每 POI 6–12 个**（基数 6 + 每高一 tier 加 2）
- 落点排除 POI 外圈入口格与紧贴墙的死角；巡逻点从出生格 BFS 可达域取（保证走得到）
- 撞墙时**扇形探测**找可行方向；卡住 1.6 秒自动换目标（不会贴墙罚站）

### 载具（照 COD-DMZ）
- **4 座**（1 驾驶 + 3 乘客），靠近按 **E** 上车、车内按 **E** 下车
- **四轮驾驶模型**：W/S 油门刹车，A/D 方向，**静止不能转向**；高速转向衰减
- 极速 620 px/s ≈ 跑速的 2.1 倍，横穿全图从 3.5 分压到 1.7 分
- **血量 420 → 55% 开始冒烟 → 归零起火 → 3.2 秒引信 → 爆炸**
- 爆炸半径 190px / 85 伤害（距离衰减）+ 留焦黑残骸 + 吸引全场小兵
- **撞墙掉血**（满速 42 伤害）、残血动力衰减到 45%
- 玩家和小兵的子弹**都能打中车** —— 车不是无敌掩体
- 全图约 28 辆：出生点附近 3 / 每 POI 外 55% / 空旷区 14，**不在 POI 内生成**
- 小地图上青=可上 / 黄=满座 / 橙=已毁

### 生命与伤害
玩家 100 HP、左下血条、**受击方向指示器**（屏幕边缘朝来袭方向亮红弧）、死亡遮罩 + F5 重开。F1 有「玩家无敌」开关专心看 AI 行为。

## 四、这一版没做（明确不在范围）

撤离点与撤离流程、局外养成与变卖、枪械配件、敌人小队协同/掩体利用/多兵种、尸体可搜刮、局域网联机（仅预留架构）、音效、美术资源。

   │  ├─ raid_log.gd        埋点与日志导出

   │  ├─ vision.gd          扇形视野 + 墙体遮断

   │  └─ player_camera.gd   跟随 + 前瞻
   ├─ world/
   │  ├─ level.gd           关卡（字符网格 → 墙/地板/容器）
   │  └─ loot_container.gd  逐格搜刮容器
   ├─ inventory/
   │  └─ grid_inventory.gd  Tetris 背包数据模型（纯数据，可被服务端复用）
   └─ ui/
      ├─ hud.gd             局内平视信息
      ├─ loot_ui.gd         搜刮面板 + 背包网格

## 六、改数值 / 改布局

| 想改什么 | 改哪里 |
|---|---|
| 手感数值（移速/视野/搜刮耗时…） | 游戏里按 **F1** 实时调，满意后点「保存数值」 |
| 关卡布局 | `scripts/world/level.gd` 的 `MAP` 常量，改字符即可 |
| 物品与格子尺寸 | `data/items.json` |
| 容器出货概率 | `data/loot_tables.json` |
| 背包尺寸 | `scripts/autoload/tuning.gd` 的 `backpack_cols` / `backpack_rows` |

## 七、联机预留说明

全项目**不直接调用** Godot multiplayer API，一切经由 `NetHub`。下一轮接局域网时：
1. 实现 `NetHub.host_lan()` / `join_lan()`（ENetMultiplayerPeer）
2. `is_authority()` 改为返回 `multiplayer.is_server()`
3. 给 `Player`（position / aim_dir / stance）与 `LootContainer`（slots / revealed / taken / cracked）加 RPC 同步——挂点已用 `TODO_NET` 标注
4. 容器互斥（同一容器只允许一人搜）接口已就位，改成服务端权威即可

业务代码无需改动。
